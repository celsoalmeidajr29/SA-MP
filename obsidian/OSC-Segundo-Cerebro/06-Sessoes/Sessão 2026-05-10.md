## 🏗️ Decisões de Arquitetura

### Storage de arquivos
- **Principal:** Google Drive do próprio usuário (15 GB grátis)
- **Fallback:** MinIO self-hosted no VPS
- Usuário conecta Drive via OAuth → bot sobe arquivos direto na conta dele
- Elimina custo de storage para usuários Pro

### Planos e limites
| Campo | Free | Pro |
|---|---|---|
| `messagesPerDay` | 50 | 99999 |
| `aiTokensPerDay` | 30000 | 0 (= ilimitado) |
| `storageBytes` | 100 MB | 10 GB |
| `maxActiveReminders` | 5 | 9999 |
| `memoryRetentionDays` | 30 | 9999 |
| `maxDocumentsPerMonth` | 3 | 9999 |
| `trialDays` | — | 7 (todos novos users) |

### Trial automático
- Ao cadastrar, `trialEndsAt = agora + 7 dias`
- messageHandler verifica `trialEndsAt > agora` → libera limites Pro
- Dashboard exibe banner com dias restantes

### Memória semântica
- `generateEmbedding(text)` → OpenAI text-embedding-3-small (1536 dims)
- Salvo no campo `embedding vector(1536)` (pgvector)
- Busca por similaridade coseno: `1 - (embedding <=> $2)`
- Só funciona no VPS (pgvector não disponível localmente via apt no sandbox)

### Autenticação
- NextAuth.js com CredentialsProvider
- bcryptjs para hash de senha
- JWT session (não database session)
- Callback JWT preenche `token.planId`, `token.trialEndsAt`

## 🧩 Fluxo de Mensagem (bot)

```
WhatsApp mensagem recebida
       ↓
messageHandler.ts
       ↓
[1] Usuário existe no DB?  → não → "Cadastre-se em seudominio.com"
[2] Trial válido?          → verifica trialEndsAt vs now
[3] Reset diário?          → se lastResetAt < hoje → reset contadores
[4] Limite mensagens?      → messagesUsedToday < plan.messagesPerDay
[5] Limite tokens?         → aiTokensUsedToday < plan.aiTokensPerDay (0=∞)
       ↓
Detectar intenção (keywords PT-BR)
  - SALVAR → saveMemory()
  - COMPROMISSO → parseAppointment() → scheduleAppointment()
  - LEMBRETE → parseReminder() → scheduleReminder()
  - ÁUDIO → transcribeAudio() → chat()
  - IMAGEM → chat(mediaBase64)
  - DOCUMENTO → summarize → upload Drive/MinIO → saveMemory()
  - DEFAULT → searchMemories() + chat() com contexto
       ↓
incrementMessages(userId, tokensUsed)
       ↓
Resposta WhatsApp
```
