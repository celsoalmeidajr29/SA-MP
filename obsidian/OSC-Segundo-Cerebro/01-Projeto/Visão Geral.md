# Visão Geral — OSC Segundo Cérebro

## O que é

O **OSC** é um chatbot para WhatsApp que funciona como uma memória pessoal inteligente. O usuário conversa normalmente pelo WhatsApp e o bot:

- Salva notas, informações, contatos, dados de saúde
- Agenda compromissos e envia notificações na hora certa
- Cria lembretes com recorrência
- Lê PDFs, imagens e áudios e os processa
- Responde perguntas com base no que foi salvo
- Integra com Google Drive, Gmail e Obsidian

## Proposta de Valor

> "Mande uma mensagem para salvar. Pergunte para lembrar."

Sem app extra. Sem aprendizado. Só WhatsApp.

## Planos
